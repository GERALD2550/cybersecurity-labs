# Cybersecurity Labs 🛡️

Hands-on labs documenting my journey toward a **SOC Analyst** role.
Each lab follows the real analyst workflow: **detect → investigate → contain → report**,
and is mapped to the [MITRE ATT&CK](https://attack.mitre.org) framework.

> I build these labs in an isolated home environment (VirtualBox) and attack only my
> own machines. The goal is to learn blue-team skills the way a real SOC uses them.
